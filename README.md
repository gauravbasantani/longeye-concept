# Longeye concept: check what the citation says

An unofficial design concept by Gaurav Basantani ([gauravbasantani.com](https://gauravbasantani.com)). Not affiliated with Longeye.

One report screen in the style of Longeye. A detective reviews a drafted case report. Every paragraph has a citation, but one paragraph says a person sold stolen tools while the interview it cites has him saying he didn't. The paragraph is flagged before it is accepted, the cited lines open beside it, and a rewrite uses only the cited words.

The case, agency, people and evidence are made up. Every number on the page is computed from the made-up evidence in `index.html`.

Live page: https://gauravbasantani.github.io/longeye-concept/
